C++的妙妙赋值法

在学习C++的过程中，一直认为编写结构体并对其进行赋值是一件麻烦的事，要进行又臭又长的代码编写，直至后来了解到一种方法，让赋值变得简单又直接，不用再使用很长的cout语句进行赋值

拼接复制法

比如在对结构体数组中的字符串进行赋值时，类似student_a，student_b，之类的赋值时，在我未"开智"之前，通常使用定义的方式进行赋值

#include <iostream>
#include <string>

struct student
{
    std::string name;
    int age;
    int score;
};

int main()
{
    student s1[6] = {
        {"student_a", 13, 79},
        {"student_b", 12, 57},
        {"student_c", 12, 74},
        {"student_d", 13, 99},
        {"student_e", 12, 81},
        {"student_f", 13, 60}
    };

    system("pause");
    return 0;
}

以这样的方式进行赋值确实有失水准，数据小一点还好，数据量大起来代码就很难看了，那么前面忘记了，总之有的兄弟，有的 可以通过使用for循环进行轮赋值，采取字符串拼接的方式进行。如可以将两个字符串进行前后拼接，如将字符串"student_“与字符"a"进行拼接，使得拼成字符串"stdent_a”。可以先将结构体中的"name"变量全部赋值"stdent_"，然后创建一个字符串数组，里面装有从"a"到"f"六个字母，用for循环拼接字符串的方式进行名字赋值

由此拓展，是不是也可以将姓氏与名字分别存放，通过for循环的方式进行拼接以组成名字，甚至可以通过引入<ctime>库进行以时间为随机种子，进行姓名的随机搭配

#include <iostream>
#include <string>
#include <ctime>   

int main()
{
  std::srand((unsigned int)std::time(nullptr));

  std::string surnames[] = {
    "李", "王", "张", "刘", "陈", "杨", "赵", "周", "吴", "郑",
    "司马", "欧阳", "诸葛", "上官", "慕容", "令狐"
  };
  int surnameCount = sizeof(surnames) / sizeof(surnames[0]);

  std::string giveNames[] = {
  "明", "伟", "芳", "强", "丽", "华", "平", "军", "静", "杰",
  "子轩", "一诺", "宇轩", "悠然", "明远", "思琪", "俊宇", "晨曦"
  };
  int giveNameCount = sizeof(giveNames) / sizeof(giveNames[0]);

  std::cout << "随机生成的10个姓名如下：" << std::endl;
  for (int i = 0; i < 10; ++i) {
      std::string surname = surnames[rand() % surnameCount];
      std::string givenName = giveNames[rand() % giveNameCount];

      std::string fullName = surname + givenName;
      std::cout << fullName << std::endl;
  }

  system("pause");
  return 0;
}
\\以上所有姓氏与名字表中的数据均由ai生成

还可以将生成的名字导入到外部文件中，此处不再展示 以上就是在C++的学习中学到的妙妙赋值法，极大程度上的减少了以定义法赋值的代码长度
